# 我用读书，为青春增色

*开头*：青春是一张素白的宣纸，等待着色彩的晕染。而我选择用《平凡的世界》这本厚重的书，在那最好的年华里，一笔一画描摹出独属于我的斑斓图景。

## 初遇，黄土情深

- 十六岁的夏天，我在旧书摊上与《平凡的世界》初次相遇。泛黄的封面上，一个农民的背影正走向无垠的黄土高原。翻开书页，扑面而来的不是墨香，而是一种粗粝的、带着尘土气息的辽阔。“一九七五年二三月间，一个平平常常的日子，细濛濛的雨丝夹着一星半点的雪花……”路遥的文字像陕北的信天游，苍凉中藏着滚烫的温度。我跟着孙少平走进县高中的食堂，看他躲在角落里啃着最便宜的黑面馍，心里竟涌起一种奇异的共鸣——原来苦难也可以被讲述得如此庄重。那天下午，窗外的梧桐叶落了满地，而我坐在窗前一动不动，任凭那片黄土地上的风沙吹进十六岁的胸膛。那一刻我知道，青春的画布上，从此多了一抹沉郁而温暖的土黄。

## 再品，命运如歌

- 十七岁的寒假，我第二次捧起这本书，在炉火旁读到了孙少平离开双水村去黄原城揽工的情节。那些深夜，他借着工棚里昏暗的灯光读书，脊背上是被石头磨出的血痂，眼睛里却映着《牛虻》与《约翰·克利斯朵夫》的光芒。我忽然在这两个平行的世界里看见了自己的影子——我们都在各自的“黄原”里挣扎，都在用读书对抗着生活的平庸。而孙少安在砖窑倒塌后蹲在河滩上痛哭的那一夜，炉火映在我脸上，我分明感到有什么滚烫的东西正从眼角滑落。原来所谓命运，就是一次次的跌倒与爬起；所谓青春，就是在最深的夜里依然相信天亮。那些人物像远方的亲人，他们流汗、流泪、流血，却始终没有松开握紧命运的手。而我在他们的故事里，学会了如何握紧自己的命运。

## 重翻，平凡铸光

- 十八岁的春天，高考前夕，我再次翻开这本被翻得卷边的书。这一次，我看见了以前不曾看见的东西——田晓霞在洪水中牺牲后，孙少平独自走上古塔山，在杜梨树下翻开她留下的三本日记，那句“不要见怪，不要见外”让整个春天都静默了。可生活还在继续，他回到大牙湾煤矿，下井，采煤，在那片黑暗的地心深处寻找光明。重读至此，我忽然懂得——平凡不是平庸，而是在认清生活的真相之后，依然热爱生活。那些曾经让我泪流满面的苦难，如今读来却成了一种庄严的祝福。高考前夕的焦虑在这重读中渐渐沉淀，我明白了，人生的考场从不只在六月，而在每一个需要选择挺立的瞬间。那本翻旧的书，像一面镜子，照见了三年来悄然长大的自己。

*结尾*：如今，那本《平凡的世界》还立在书桌最顺手的位置，书页间夹着三年来落下的银杏叶、梧桐叶和一片不知名的花瓣。读书给予我的，不只是一个故事，而是一种在平凡中仰望星空的勇气。当路遥的文字渗入血脉，青春便不再惧怕黯淡——因为在那些黄土般质朴的字句里，我早已看见，最平凡的生命，也能活成一道光。
